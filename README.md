# Object Detection and Recognition

## 1. Project Overview

This project focuses on learning image collection, object detection, image annotation, and recognition using machine learning and computer vision techniques.

## 2. Project Objectives

* Collect a sample dataset of images.
* Organize images using Google Drive.
* Learn to annotate images and label objects.
* Study machine learning algorithms, including linear regression and logistic regression.
* Learn how to evaluate classification models using a confusion matrix, ROC curve, and AUC.
* Explore object detection tools and techniques.

## 3. Tools and Technologies

* **Google Drive:** Image dataset storage and organization.
* **GitHub:** Source control and project documentation.
* **Python:** Machine learning and data processing.
* **Ollama:** Running the Llama 3.2 1B language model locally.
* **Ultralytics:** Computer vision and object detection tools.

## 4. Dataset Organization

The dataset will be organized into the following folders:

* `01_Raw_Images` — original collected images.
* `02_Annotated_Images` — images with annotations.
* `03_Labels` — annotation labels and related files.
* `04_Reports` — project reports and evaluation results.

## 5. Project Workflow

1. Collect the initial image dataset.
2. Organize images in Google Drive.
3. Annotate images and assign labels.
4. Study machine learning and classification techniques.
5. Explore object detection models.
6. Evaluate and document the project results.
